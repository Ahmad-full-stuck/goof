# وكالة دبي — متجر هدايا تجريبي

واجهة عربية RTL بهوية كحلية وذهبية وعاجية، مصممة لعرض تجربة التسوق للهدايا من الهاتف واللوحي والكمبيوتر.

## النشر

يعمل GitHub Actions على نشر ملف `index.html` إلى GitHub Pages عند تحديث الفرع `main`. بعد نجاح سير العمل يظهر رابط النشر في تبويب **Actions** أو **Settings → Pages**.

## ما الذي يعمل في النسخة المنشورة؟

- عرض مجموعات الهدايا والمنتجات والبحث والفرز.
- التصفية حسب التصنيف، المفضلة، حقيبة التسوق والكميات.
- نموذج الطلب، رقم مرجعي، وتتبع الطلبات داخل نسخة المعاينة.
- تبديل الوضع النهاري والليلي.
- لوحة معاينة للطلبات على المتصفح نفسه.

## حدود نسخة GitHub Pages

GitHub Pages يستضيف ملفات الواجهة الثابتة فقط. في هذه النسخة التجريبية، تُحفظ الطلبات في `localStorage` على المتصفح الحالي؛ لا تُرسل إلى خادم، ولا تظهر تلقائيًا لدى أجهزة أو متصفحات أخرى، ولا تُعد لوحة الإدارة المصغرة نظامًا آمنًا. يلزم نشر Worker وربطه بقاعدة بيانات D1 قبل الاستخدام الفعلي أو استقبال بيانات زبائن حقيقية.

الأسعار والمنتجات الظاهرة هي محتوى تجريبي قابل للتعديل وليست تأكيدًا لقائمة الأسعار الرسمية للمتجر.

## هوية العلامة
